Privacy policy

WattTrail reads battery and system measurements to display them on your Mac. It does not collect, upload, or share personal data or system measurements. The app does not use analytics, advertisements, accounts, or network connections.

If you enable Bluetooth batteries, WattTrail reads the display names and battery levels of compatible accessories already connected to your Mac. It uses this data in memory to populate the panel. The feature is optional and you can disable it in the panel.

Recent battery draw, battery temperature, CPU, and memory samples are held in memory while the app is running. WattTrail keeps up to seven days of battery-session summaries and load events in a local file in its app container. A load event can include the name and CPU usage of the most active app when a per-app reading is available. WattTrail may read app names and CPU usage while the panel is open or alerts are enabled. If you run a Shortcuts or AppleScript action, WattTrail returns only the requested snapshot to the automation on your Mac.

The menu bar, Bluetooth, power profile and notification preferences are stored locally in macOS app preferences. To remove those preferences, delete the app and its local app data using macOS.

This policy describes the operation of WattTrail 1.8.
